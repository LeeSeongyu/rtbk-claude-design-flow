# design-system

`data/00-core-ui/`에 수집된 코어 UI 구조 데이터와 디자인 변수(토큰)를 근거로,
구현 코드가 디자인 시스템과 **일관되게** 작성되도록 돕는 스킬입니다.

## 목적

- 색상·타이포그래피·간격·반경·그림자 등을 **토큰**으로 참조한다 (하드코딩 금지).
- 반복되는 UI는 **컴포넌트**로 재사용한다.
- 레퍼런스와의 구조·패턴 일치도를 높여 `visual-verdict` 통과 가능성을 올린다.

## 입력 소스

- `data/00-core-ui/variables.json` (또는 유사) — 디자인 변수/토큰
- `data/00-core-ui/design-context.md` — 레이아웃·스타일 컨텍스트
- `data/00-core-ui/screenshots/` — 시각 기준

## 적용 규칙

1. **토큰 우선**
   - 색상·간격·타이포·반경 값은 코어 UI 변수에서 가져온다.
   - 매칭되는 토큰이 없으면 가장 가까운 토큰을 쓰고, 새 값 도입 시 근거를 주석으로 남긴다.
2. **컴포넌트 재사용**
   - 버튼·인풋·카드 등 반복 요소는 공통 컴포넌트로 만든다.
   - 변형(variant)은 상태/사이즈 단위로 분리한다.
3. **레이아웃 일관성**
   - 간격/정렬은 토큰화된 스케일을 따른다.
   - 반응형이 필요한 경우 상대 단위와 유연한 레이아웃을 사용한다.
4. **접근성 기본값**
   - 대비, 포커스 표시, 시맨틱 마크업을 기본으로 지킨다.

## 산출 기준 (체크리스트)

- [ ] 색상/간격/타이포가 토큰으로 참조되는가?
- [ ] 반복 UI가 컴포넌트로 분리됐는가?
- [ ] 레퍼런스의 구조·패턴과 배치가 일치하는가?
- [ ] 하드코딩된 매직 넘버가 없는가 (있다면 근거 주석)?

## 비고

- 이 스킬은 **픽셀 단위 복제**가 목표가 아니다. 구조·패턴·토큰 일관성을 지향한다.
- 채점 기준은 `visual-verdict` 스킬과 정렬되어 있다.
