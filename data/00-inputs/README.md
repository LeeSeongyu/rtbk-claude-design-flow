# 00-inputs — 사람이 넣는 재료

각 하위 폴더에 재료를 넣으세요. 에이전트는 여기 있는 자료만 근거로 작업합니다 (임의 상상 금지).

| 폴더 | 넣을 것 | 사용 단계 |
|---|---|---|
| `service-diagram/` | Service Diagram 이미지 + `service-diagram.md` | Step 1 |
| `IA/` | 정보구조 이미지 + `IA.md` | Step 1 |
| `fruto-design/` | fruto Figma 파일 URL (`fruto-source.md`) — 비주얼 **값**의 원본 | Step 2 |
| `carbon-format/` | Carbon v11 양식 (파일 또는 URL) — 디자인 시스템 **형식**의 기준 | Step 2 |
| `wireframes/` | 기획초안 스케치/와이어프레임 | Step 3·5 참고 |
| `competitors/` | 경쟁서비스 URL 목록/캡처 (`competitors.md`) | Step 3 |

> `service-diagram.md`와 `IA.md`는 **사람이 직접 작성**합니다.
> 이미지만으로 추측한 부분은 문서에 신뢰도(High/Medium/Low)를 표기해두면 좋습니다.
