# 정보구조 (IA) — RTBK **회계사무소 측 웹** (accounting)

> 기준 이미지 `IA_accounting.png` 를 **박스 단위로 전사**. 위계: 메인 탭 > 화면 > 구성 요소 > 세부 구성요소, 팝업 = 오버레이. 색 = 파랑.

## 메인 탭 1 — 1. 회원가입/로그인
(업체 측 웹과 동일)

- **이메일 로그인** (진입점)
  - → 이메일(ID) / 비밀번호 ─────────────→ 메인화면
  - → 카카오로 시작하기
    - → 카카오 메일 아이디·이메일·전화번호
      - 비밀번호
    - → 카카오톡 인증 ──────────→ 메인화면
  - → 네이버로 시작하기
    - → 네이버 메일 아이디·이메일·전화번호
      - 비밀번호
    - → 네이버 약관 동의 ────────→ 메인화면
- **메인화면** (로그인 성공 도착점)
- **비밀번호 찾기**
- **이메일 찾기**

## 메인 탭 2 — 부가가치세

### 화면: 의뢰 관리
- 구성 요소 — **의뢰 업체 리스트**
  - 세부: 업체명·날짜·연락처
  - 세부: 부가세 신고서 (첨부)
  - 세부: 카드내역서 (첨부)
  - 세부: 상태·필터·정렬
- 액션 (리스트에서 진입):
  - **검토하기** → 팝업 `검토`
  - **Note Taking 확인하기** → 팝업 `Note Taking 확인`
  - **업체 연락하기**

### 화면: 신고서 작성
- 구성 요소 — **검토 완료 의뢰 리스트**
  - 세부: 제출하기
  - 세부 〔강조·핑크〕: 문서 생성하기
- 구성 요소 — **신고 제출서 리스트**

### 팝업: 검토
- 구성 요소 — **1차_AI 검토 내역**
  - 세부: 항목별 공제·비공제 (토글)
  - 세부: 항목별 공제·비공제 분류 설명
  - 세부: 수정하기
  - 세부: 완료하기
- 구성 요소 — **2차 회계사 검토**
  - 세부: 카드내역 리스트
  - 세부: 공제·비공제 토글
  - 세부: 카드 소유주별 확인
  - 세부: 불분명 지출 표시·선택
  - 세부: 업체 연락하기
  - 세부: 검토 요청

### 팝업: Note Taking 확인
- 구성 요소 — **카드내역 리스트 + Note taking 내용**
  - 세부: 항목별 공제·비공제 (토글)
  - 세부: 항목별 공제·비공제 분류 설명
  - 세부: 완료하기
  - 세부: 불분명 지출 표시·선택
  - 세부: 업체 연락하기
  - 세부: 검토 요청
