# 정보구조 (IA) — RTBK **업체 측 웹** (customer)

> 기준 이미지 `IA_customer.png` 를 **박스 단위로 전사**. 위계: 메인 탭 > 화면 > 구성 요소 > 세부 구성요소, 팝업 = 오버레이.

## 메인 탭 1 — 1. 회원가입/로그인

- **이메일 로그인** (진입점)
  - → 이메일(ID) / 비밀번호 ─────────────→ 메인화면
  - → 카카오로 시작하기
    - → 카카오 메일 아이디·이메일·전화번호
      - 비밀번호
    - → 카카오톡 인증 ──────────→ 메인화면
  - → 네이버로 시작하기
    - → 네이버 메일 아이디·이메일·전화번호
      - 비밀번호
    - → 네이버 약관 동의 ────────→ 메인화면
- **메인화면** (로그인 성공 도착점)
- **비밀번호 찾기**
- **이메일 찾기**

## 메인 탭 2 — 부가가치세

### 화면: 문서 관리 (like Dropbox)
- 구성 요소 — **문서 리스트**
  - 세부: 업로드
  - 세부: 삭제
  - 세부: 의뢰하기
  - 세부: 부가가치세 신고서
  - 세부: 세액 공제 내역
  - *문서 리스트 선택 후 의뢰 → `의뢰 결정 단계`*
- 팝업 — **의뢰 결정 단계**
  - 세부: 예상 절감액 및 환급부담금 확인
  - 세부: 의뢰 진행 여부
- 팝업 — **의뢰 예약금 결재**
  - 세부: 의뢰 예약금 결재 관련 안내사항
  - 세부: 결재 창

### 화면: 의뢰 관리
- 구성 요소 — **의뢰 리스트**
  - 세부: 프로그래스 바 (의뢰 진행 단계_검토/noting → n차)
  - 세부: Note Taking
  - *알림 화면에서 요청 아이템 클릭 or 리스트 아이템 활성 버튼 클릭 → `Note Taking`*
- 팝업 — **Note Taking**
  - 세부: 검토 요청 항목 (1 per 팝업 페이지)
  - 세부: Input box
  - 세부: 임시저장 (or 저장)
- 팝업 — **회신**
  - 세부: Note Taking 한 내용 회신만 회신하기
  - 세부 〔강조·핑크〕: 영상통화·통화·메시지 기능을 통한 소통하기 (실시간 소통)
