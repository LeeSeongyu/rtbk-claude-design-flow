# carbon-format — 디자인 시스템 "형식"의 출처 (Carbon Design System v11)

이 폴더에 **디자인 시스템을 어떤 양식/구조로 짤지**의 기준인 **Carbon Design System v11** 참고본을 넣으세요.

`02-design-system-builder`가 여기 양식을 읽어, **형식·토큰 네이밍·컴포넌트 분류·상태 체계**를
Carbon v11대로 잡고, 실제 **값은 fruto Figma에서** 채웁니다.

## 넣을 것 (아래 중 하나)
- `carbon-v11.md`에 참고할 Carbon v11 문서 **URL**과 따라야 할 범위(색/타입/스페이싱/모션/컴포넌트 등)
-**URL**: https://www.figma.com/design/rWE1PCtsuXVscRbJFkkqNa/-v11--Carbon-Design-System--Community-?node-id=58-2763&t=JPLXabsUiYL5Owsr-1

## 형식 vs 값 (헷갈리지 않게)

- **형식(여기, Carbon v11)** — "토큰을 어떤 카테고리·이름·상태 체계로 조직하는가"
- **값(fruto Figma)** — "그 토큰의 실제 색/사이즈/간격은 무엇인가"

> 값을 fruto에서 못 찾으면 `미확인`으로 두고 사람이 확정합니다. 형식을 임의로 바꾸지 않습니다.
> 파일이 없으면 Step 2는 사람에게 요청하며, 공개 IBM Carbon v11 문서를 대신 참고할지 확인합니다.
