# case-screens — 케이스 상태 대장

각 케이스(화면)의 진행 상태를 추적하는 대장입니다.

## 상태 값

- `생성중` — 화면 구현 진행 중 또는 1차 채점 미통과(visual-verdict < 85)
- `검토중` — 1차 채점 통과(≥ 85), 코드 리뷰 대기/진행 중
- `완료` — 코드 리뷰 PASS

> 상태는 `01-case-deriver`(Step 2)와 메인 세션의 코드 리뷰 오케스트레이션이 갱신합니다.
> **완료는 코드 리뷰 PASS 시점에만 표기합니다.**
